# Changelog

Формат: Keep a Changelog. Версии — `v0.x.y` до релиза (см. docs/versions.md). PDF-версия комплекта документов — docs/pdf/.

## [0.1.0] — 2026-10-27

Полная замена прототипа зрелой платформой. Ветка `v0.1.0`, автор ayurasov (исполнение — ИИ-ассистент ZCode/GLM).

### Добавлено

- **Сервер** (`server/`): NestJS 11 + TypeScript strict + Prisma 6 + PostgreSQL 17. Аутентификация (scrypt, JWT access 15 мин, refresh с ротацией в httpOnly-cookie, pw-версия пароля), глобальные guards с `@Public`, заявки с конечным автоматом (перенос `changeFrom`, удаление `pendingDeletion`, авто-approve за подчинённого), пересечения 409, жёсткий лимит баланса (политика в настройках), ТК РФ 14 дней, график интервалами с конфликтами отделов, производственный календарь 2026–2027, справочники (отделы/проекты/группы), настройки организации, append-only аудит в одной транзакции с изменениями, уведомления, `/healthz`+`/readyz`, Swagger на `/api/docs`. Ошибки — RFC 9457 по каталогу документов 2.
- **Клиент** (`web/`): Vue 3 + Vite + TypeScript + Pinia + vue-router, без компонентных библиотек. Дизайн-система по внутренним референсам (токены todo-planner, тёмная тема puls/gantt): экраны входа, графика-гант (фильтры, легенда, конфликты), «Мой отпуск» (KPI, заявка, уведомления, ТК-предупреждение), согласования (одобрение/отклонение с причиной), сотрудники (CRUD, одноразовый пароль, пагинация, поиск), справочники, настройки (порог конфликта, политика лимита, смена пароля), аудит. Light/dark, адаптив до мобильных.
- **Поставка**: `docker-compose.yml` (postgres 17 / server / web за nginx), multi-stage Dockerfile'ы, миграции Prisma при старте, `Makefile`.
- **Миграция данных прототипа**: `server/prisma/seed.ts` — 131 сотрудник (id и логины сохранены, пароли в scrypt), 14 отделов, 268 заявок, недельные шаблоны режимов.
- **SBOM и лицензии**: CycloneDX 1.5 на оба пакета (`make sbom`), автогенерируемый отчёт `docs/sbom/licenses-report.md` с классификацией для реестра ОП (691 компонент, все лицензии разрешительные); документ 11.
- **Тесты**: 19 e2e (vitest + supertest + unplugin-swc; сервер на тестовой БД vacation_test) — аутентификация, ротация refresh, RBAC, жизненный цикл заявок, лимиты, аудит; дымовой скрипт 17 проверок.
- **Документация**: комплект 00–11 (архитектура 2.0 под зрелый стек), PDF-версии в `docs/pdf/`, история версий и авторство `docs/versions.md`.

### Удалено

- Прототип: `server.js`, `public/index.html`, snapshot-протокол `PUT /api/state`, `install.bat`/`start.bat`, README-Windows (git-история сохраняет всё).

### Безопасность

- Пароли только scrypt-хеши; пароли/токены отсутствуют в журналах, ответах и выгрузках; единая 401-ошибка входа без раскрытия причины; повторное использование refresh-токена отклоняется ротацией.
