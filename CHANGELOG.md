# Changelog

Формат: Keep a Changelog; версии — semver.

## [1.1.0] — 2026-10-27

Этап 0: приведение репозитория в порядок, каркас разработки и целевая архитектура.

### Добавлено

- Комплект архитектурных документов 0–10 (`docs/specs/`), ADR-001…008, журнал решений, журнал этапа.
- Целевой контракт API v1: `contracts/openapi-vacation-api-v1.yaml` (26 путей, 39 операций) и валидатор `npm run contract:check`.
- CI GitHub Actions: ESLint + тесты + контракт (Node 20/22) + дымовой запуск сервера.
- Интеграционные тесты API (`test/api.test.js`): health, seed-инициализация, roundtrip состояния, валидация 400, reset, SPA-fallback.
- ESLint 9 (flat config), шаблон PR, CODEOWNERS, AGENTS.md, промпты для ИИ-ассистентов (`prompts/`).
- README с быстрым стартом и картой документации.

### Изменено

- Сервер разделён на модули: `src/app.js` (фабрика приложения, тестируемая без порта), `src/db.js` (схема, seed, слой данных), `server.js` — тонкая точка входа.
- `package.json`: имя `vacation-planner`, Node >=20, скрипты test/lint/dev/contract:check.

### Безопасность

- Рабочая БД (`data.db*`) исключена из git (`.gitignore`); наполнение — автоматически из `seed.json`.
- Отключён заголовок `X-Powered-By`.

### Известные ограничения этапа 0 (закрываются на этапе 1, см. docs/specs/00-feature-audit.md)

- Протокол `PUT /api/state` остаётся снимком целиком (гонки last-write-wins).
- Пароли в демо-данных — открытый текст; API не требует аутентификации.
- Год и календарь праздников зашиты в клиент (2026).

## [1.0.0] — 2026-10

Начальная версия: планировщик отпусков, SPA + Express/SQLite, seed на 131 сотрудника.
