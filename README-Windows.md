# Планировщик отпусков — запуск на Windows

Веб-приложение: бэкенд Node.js + Express, данные хранятся в локальной БД SQLite (`data.db`).

## 1. Установить Node.js (один раз)

Скачайте и установите **Node.js LTS (версия 18 или новее)**: https://nodejs.org/

В установщике рекомендуется оставить галочку **«Automatically install the necessary tools»** — это поставит инструменты сборки, нужные для нативного модуля `better-sqlite3`.

## 2. Установить зависимости (один раз)

Дважды кликните **`install.bat`**.

Скрипт проверит Node.js и выполнит `npm install`. Модуль `better-sqlite3` соберётся под вашу версию Windows автоматически (1–3 минуты при первом запуске).

> Альтернатива через командную строку: откройте папку проекта в PowerShell или CMD и выполните `npm install`.

## 3. Запустить

Дважды кликните **`start.bat`**.

Откроется окно сервера, и через пару секунд браузер сам перейдёт на адрес:

```
http://localhost:3000
```

Вход (учётная запись администратора):
- Логин: `yurasov.av`
- Пароль: `j2ENXpPi`

Чтобы остановить сервер — закройте окно или нажмите `Ctrl + C`.

## Сменить порт

Если порт 3000 занят, запустите так (CMD):

```cmd
set PORT=8080
npm start
```

или отредактируйте строку `set PORT=3000` в `start.bat`.

## Где хранятся данные

- Файл **`data.db`** в папке проекта — это база со всеми сотрудниками, отпусками, правами и настройками.
- При первом запуске база создаётся автоматически из `seed.json` (131 сотрудник).
- Чтобы сбросить всё к исходному состоянию: остановите сервер, удалите файлы `data.db`, `data.db-wal`, `data.db-shm` и запустите снова. (То же самое делает кнопка сброса в интерфейсе.)
- Для резервной копии достаточно скопировать файл `data.db`.

## Импорт / экспорт

- В разделе **«Сотрудники»** есть кнопки выгрузки и загрузки XLSX.
- Колонки **«Права администратора»** и **«Отпуска»** теперь экспортируются и импортируются.
  Формат ячейки «Отпуска»: периоды через `; `, например `2026-06-10..2026-06-21; 2026-09-14..2026-09-20`.

## Возможные проблемы

- **«node не является внутренней или внешней командой»** — Node.js не установлен или не добавлен в PATH. Переустановите Node.js LTS и перезапустите окно.
- **Ошибка сборки `better-sqlite3`** — установите «Desktop development with C++» через Visual Studio Build Tools, либо переустановите Node.js LTS с галочкой автоустановки инструментов, затем снова запустите `Установка.bat`.
- **Нельзя копировать `node_modules` с другого компьютера/ОС** (например, с Linux) — нативный модуль не запустится. На каждой машине выполняйте `npm install` заново.
