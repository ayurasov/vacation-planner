# О документе

Документ — единый справочник текстов «Планировщика отпусков»: правила написания, сообщения интерфейса, уведомления и заголовки ошибок API. Тексты приведены в том виде, в каком они реализованы в версии 0.5.0; изменение текста в коде сопровождается правкой этого документа в том же PR.

| Где живут тексты | Что |
|---|---|
| `web/src/views`, `web/src/components` | Подписи, подсказки, всплывающие сообщения, диалоги |
| `server/src/infra/problems.ts` | Заголовки (`title`) ошибок problem+json |
| `server/src/requests/requests.service.ts` | Тексты уведомлений |
| `server/src/analytics/coverage.ts` | Выводы аналитики и пояснения подбора дат |

# Правила написания

1. Обращение на «вы», спокойный тон, без восклицательных знаков и прописных букв для акцента.
2. Сначала что случилось, затем что делать. Не больше двух коротких предложений.
3. Причина конкретная: поле, дата, число. Коды ошибок в тексте не показываются — они в теле problem+json.
4. Числа с единицами: «14 календарных дней», «11 дней отпуска»; в таблицах допускается «дн.» и «к.д.».
5. Термины по-русски: отпуск, заявка, согласовать, отклонить, перенос, график работы.
6. Ссылка на закон — номер статьи в скобках: «(ТК РФ, ст. 120)».
7. Подтверждение необратимого действия называет объект и последствие: «Уволить Иванова И. И.?» — «Учётная запись будет отключена».

# Вход и сеанс

| Ситуация | Текст |
|---|---|
| Неверный логин или пароль | Неверный логин или пароль. Проверьте раскладку и Caps Lock. |
| Превышен лимит попыток | Слишком много попыток входа. Подождите минуту и попробуйте снова. |
| Пароль изменён | Пароль изменён. Войдите с новым паролем. |
| Новый пароль не совпадает с подтверждением | Новый пароль и подтверждение не совпадают |
| Сеанс потерян: пароль сменён, учётная запись отключена или refresh истёк (экран входа, `?ended=1`) | Сеанс завершён: пароль изменён, учётная запись отключена или вы долго не входили. Войдите снова. |
| Сервер недоступен при входе (нет ответа) | Нет связи с сервером. Проверьте подключение и попробуйте снова. |
| Сервер перегружен при входе или в любом действии (503) | Сервис перегружен. Повторите через несколько секунд. |
| Учётная запись заблокирована (423, верный пароль) | Учётная запись заблокирована до {время} после неудачных попыток входа. Повторите позже или обратитесь в кадровую службу |

| Пароль короче политики | Пароль должен быть не короче {N} символов |
| Пароль из одного-двух символов | Пароль не должен состоять из одного-двух повторяющихся символов |
| Последовательность | Пароль не должен быть последовательностью символов на клавиатуре или в алфавите |
| Распространённый пароль | Этот пароль слишком распространён — его подбирают первым |
| Логин или фамилия в пароле | Пароль не должен содержать логин · Пароль не должен содержать фамилию |
| Новый пароль равен текущему | Новый пароль совпадает с текущим |

# Письма

Письмо повторяет текст уведомления и добавляет обращение по имени и отчеству, ссылку на нужный раздел и подпись с инструкцией по отписке (`server/src/mail/letters.ts`).

| Вид | Тема | Ссылка |
|---|---|---|
| `request_created` | Заявка на согласование: {ФИО} | `/approvals` |
| `request_approved` | Отпуск согласован | `/my` |
| `request_rejected` | Заявка на отпуск отклонена | `/my` |
| `request_cancelled` | Отпуск удалён | `/my` |
| `weekly_digest` | Отпуска на неделе {даты} | `/schedule`, `/approvals` |
| `request_escalated` | Заявка ждёт решения | `/approvals` |
| `request_stalled` | Заявка без решения | `/employees` |
| `delegation_assigned` | Вам передано согласование заявок | `/approvals` |
| `account_locked` | Учётная запись временно заблокирована | `/settings` |
| `password_changed` | Пароль изменён | `/settings` |
| `vacation_notice` | Извещение о начале отпуска | `/my` |
| `planning_open` | Планирование отпусков | `/my` |
| `planning_reminder` | Напоминание: запланируйте отпуск | `/my` |

Сводка: «На неделе {даты} в отпуске {N} сотрудников: • {ФИО} — {даты} (с {день})… Ждут вашего решения: {N} заявок». Если отсутствующих и ожидающих заявок нет, сводка не отправляется.

Тексты уведомлений с v0.4.0 пишут даты по-русски: «Новая заявка на отпуск 1–14 июля 2027 (14 к. д.)», «Перенос отпуска на 3–9 августа 2027 отклонён, остаются прежние даты 1–7 июля 2027. Причина: …», «Запрос на удаление отпуска 1–14 июля 2027 отклонён — отпуск остаётся».

# Согласование текстов

Тексты проверяет кадровая служба на соответствие локальным актам об отпусках. Тексты интерфейса и уведомлений меняются обычным PR; заголовки ошибок — только вместе с каталогом документа 2 и контрактом.
