# Тексты сообщений пользователя

| Параметр | Значение |
|---|---|
| Документ | Тексты сообщений (документ 5 комплекта) |
| Версия | 1.0 |
| Дата | 27.10.2026 |
| Статус | На согласовании |
| Связанные документы | 2 — Спецификация API (каталог ошибок); 8 — ТЗ |

## 1. Назначение

Единый источник текстейзов интерфейса, уведомлений и ошибок этапа 1. Тексты хранятся в клиенте и сервере без дублирования: серверные — только для проблем RFC 9457 (`title`) и уведомлений.

## 2. Правила написания

1. Обращение на «вы», строчными, без восклицаний.
2. Что случилось → что делать дальше. Не более двух предложений.
3. Причина ошибки — конкретная (поле, дата, число), без кодов в тексте; код — в теле проблемы.
4. Числа с единицами: «14 календарных дней», «5 дней отпуска».
5. Иностранные термины не используем: отпуск, заявка, согласовать, отклонить.

## 3. Вход и сессия

| Ключ | Текст |
|---|---|
| login.title | Планировщик отпусков |
| login.hint | Введите корпоративный логин и пароль |
| login.error.credentials | Неверный логин или пароль. Проверьте раскладку и Caps Lock. |
| login.error.rate | Слишком много попыток. Повторите через минуту. |
| login.must.change.password | Установите новый пароль: одноразовый пароль больше не действует |
| session.expired | Сессия истекла. Войдите заново. |

## 4. Заявки на отпуск

| Ключ | Текст |
|---|---|
| request.create.title | Заявка на отпуск |
| request.days.preview | {calendar} календарных дней, из них рабочих {work} |
| request.overlap.error | Эти даты пересекаются с уже поданным отпуском. Выберите другой период. |
| request.limit.error | Остаток дней исчерпан: доступно {remaining}. Обратитесь к администратору для перерасхода. |
| request.limit.warn | Заявка превышает остаток ({remaining} дн.). Руководитель увидит предупреждение. |
| request.sent | Заявка отправлена руководителю {manager} |
| request.auto.approved | Отпуск оформлен: за подчинённого согласование не требуется |
| request.conflict.warn | Внимание: в этот период в отделе «{dept}» отсутствуют уже {percent} сотрудников (порог {threshold} %) |
| request.tk.warn | По ТК РФ одна из частей отпуска должна быть не короче 14 календарных дней подряд. Сейчас такой части нет. |
| request.transfer.hint | Перенос одобренного отпуска отправляется на повторное согласование; прежние даты действуют до решения. |
| request.deletion.hint | Удаление одобренного отпуска подтверждает руководитель. |

## 5. Решения и очередь согласования

| Ключ | Текст |
|---|---|
| approve.action | Согласовать |
| reject.action | Отклонить |
| reject.comment.required | Укажите причину отклонения — она станет видна автору заявки |
| approve.queue.empty | Заявок к согласованию нет |
| approve.queue.item | {name} просит отпуск {range} ({days} календарных дней) |
| approve.done | Заявка согласована. Автор получит уведомление. |
| reject.done | Заявка отклонена. Автор получит уведомление с вашей причиной. |

## 6. Уведомления (интерфейс)

| kind | Текст |
|---|---|
| request_created | {name} просит согласовать отпуск {range} |
| request_approved | Отпуск {range} согласован {manager} |
| request_rejected | Заявка на отпуск {range} отклонена. Причина: {comment} |
| request_cancelled | Автор отменил заявку на отпуск {range} |
| conflict_warning | В отделе «{dept}» {date} превышен порог отсутствия |

## 7. Ошибки API (title для problem+json)

| Код | title |
|---|---|
| auth/invalid-credentials | Неверный логин или пароль |
| auth/token-expired | Сессия истекла |
| auth/forbidden | Недостаточно прав для этого действия |
| validation/invalid-field | Некорректно заполнено поле {field} |
| validation/bad-date-range | Дата окончания раньше даты начала или даты в прошлом |
| not-found | Записано не существует или удалено |
| overlapping-request | Период пересекается с существующей заявкой |
| limit-exceeded | Превышен остаток дней отпуска |
| stale-state | Данные изменились: обновите страницу и повторите |
| last-admin | Нельзя удалить или разжаловать последнего администратора |
| department-not-empty | В отделе ещё есть сотрудники |
| rate-limited | Слишком много запросов. Повторите позже. |
| calendar-missing | Для {year} года не загружен производственный календарь. Обратитесь к администратору. |

## 8. Письма (этап 2 — заготовки)

| Шаблон | Тема | Первая строка |
|---|---|---|
| new_request | Согласование: отпуск {name} {range} | {name} просит отпуск {range}. Откройте планировщик, чтобы согласовать. |
| decision | Решение по вашей заявке | Ваш отпуск {range} {одобрен|отклонён}. Причина: {comment}. |
| weekly_digest | Отпуска на следующую неделю | На следующей неделе в отпуске {n} сотрудников вашего отдела. |

## 9. Согласование

Тексты проверяет HR-служба на соответствие локальным актам (правила отпусков). Изменение текстов разделов 4–6 — без ревью ТЛ; раздел 7 — только вместе с каталогом ошибок документа 2.
