# О документе

Документ — единый справочник текстов «Планировщика отпусков»: правила написания, сообщения интерфейса, уведомления и заголовки ошибок API. Тексты приведены в том виде, в каком они реализованы в версии 0.3.0; изменение текста в коде сопровождается правкой этого документа в том же PR.

| Где живут тексты | Что |
|---|---|
| `web/src/views`, `web/src/components` | Подписи, подсказки, всплывающие сообщения, диалоги |
| `server/src/infra/problems.ts` | Заголовки (`title`) ошибок problem+json |
| `server/src/requests/requests.service.ts` | Тексты уведомлений |
| `server/src/analytics/coverage.ts` | Выводы аналитики и пояснения подбора дат |

# Правила написания

1. Обращение на «вы», спокойный тон, без восклицательных знаков и прописных букв для акцента.
2. Сначала что случилось, затем что делать. Не больше двух коротких предложений.
3. Причина конкретная: поле, дата, число. Коды ошибок в тексте не показываются — они в теле problem+json.
4. Числа с единицами: «14 календарных дней», «11 дней отпуска»; в таблицах допускается «дн.» и «к.д.».
5. Термины по-русски: отпуск, заявка, согласовать, отклонить, перенос, график работы.
6. Ссылка на закон — номер статьи в скобках: «(ТК РФ, ст. 120)».
7. Подтверждение необратимого действия называет объект и последствие: «Уволить Иванова И. И.?» — «Учётная запись будет отключена».

# Вход и сеанс

| Ситуация | Текст |
|---|---|
| Неверный логин или пароль | Неверный логин или пароль. Проверьте раскладку и Caps Lock. |
| Превышен лимит попыток | Слишком много попыток входа. Подождите минуту и попробуйте снова. |
| Пароль изменён | Пароль изменён. Войдите с новым паролем. |
| Новый пароль не совпадает с подтверждением | Новый пароль и подтверждение не совпадают |

# Мой отпуск и заявки

| Ситуация | Текст |
|---|---|
| Баланс | Доступно для планирования в {год} году |
| Нет отпусков | Отпуск ещё не запланирован |
| ИП, самозанятый | Отпуск не предусмотрен. Для индивидуальных предпринимателей и самозанятых ежегодный отпуск не оформляется. График коллег доступен в разделе «График отпусков». |
| Сотрудник в отпуске | Сейчас вы в отпуске |
| Заголовок формы | Новая заявка на отпуск · Перенос отпуска · Отпуск сотрудника |
| Подсказка новой заявки | Заявка уйдёт руководителю на согласование. |
| Подсказка переноса | Новые даты уйдут на согласование. |
| Оформление за подчинённого | Оформляется руководителем — сразу согласован. |
| Праздники в периоде | Праздники — не в счёт отпуска (ТК РФ, ст. 120). |
| Часть в 14 дней есть | Часть отпуска не короче 14 дней — требование ТК РФ (ст. 125) выполняется. |
| Не хватает дней, жёсткая политика | Не хватает дней: доступно {N}. Сократите период — по правилам организации превышать остаток нельзя. |
| Не хватает дней, мягкая политика | Дней больше, чем доступно ({N}). Заявку можно отправить — решение примет руководитель. |
| Комментарий | Комментарий для руководителя — например: семейная поездка, билеты уже куплены |
| Отправлено | Заявка отправлена руководителю · Перенос отправлен на согласование |
| Оформлено за сотрудника | Отпуск сотрудника оформлен и согласован |
| Отмена заявки на согласовании | Отменить заявку? — Заявка ещё не согласована и будет отменена сразу. |
| Удаление согласованного отпуска | Запросить удаление отпуска? — Отпуск согласован — удаление тоже согласует руководитель. |
| Результат | Заявка отменена · Запрос на удаление отправлен руководителю |

# Подбор дат

| Ситуация | Текст |
|---|---|
| Кнопка | Подобрать лучшие даты |
| Нагрузка варианта | Наибольшая доля отдела в отпуске в эти дни, включая вас: {доля} |
| Нет вариантов | Подходящих окон нет: в эти даты отдел уже слишком загружен. Расширьте период или сократите длительность. |
| Конец года | До конца года меньше трёх месяцев — ищем на полгода вперёд |

# Согласование

| Ситуация | Текст |
|---|---|
| Пусто | Все заявки рассмотрены. Новые заявки подчинённых появятся здесь и в колокольчике уведомлений. |
| Пусто во вкладке | В этой категории заявок нет |
| Пересечения | Пересечения в отделе: {ФИО, даты} · Пересечений с коллегами по отделу нет |
| Отклонение | Отклонить заявку — {ФИО}. Причина отклонения (обязательно) |
| Отклонение переноса | Отпуск останется на прежних датах. |
| Отклонение удаления | Отпуск останется согласованным. |
| Результат | Заявка отклонена, сотрудник получит уведомление с причиной · Удаление отпуска согласовано: {ФИО} |

|---|---|---|

| `request_created` | Руководитель | {ФИО}: Запрос переноса отпуска на {начало} — {конец} |
| `request_created` | Руководитель | {ФИО}: Запрос на удаление одобренного отпуска |
| `request_approved` | Сотрудник | Отпуск {начало} — {конец} согласован |
| `request_rejected` | Сотрудник | Заявка отклонена. Причина: {комментарий} |
| `request_cancelled` | Сотрудник | Отпуск удалён по согласованию с руководителем |

# Выводы аналитики

| Вывод | Текст |
|---|---|
| Конфликт | Выше порога {доля}: {ФИО, …} и ещё {N}. Проверьте замещение или предложите перенос. |
| Пиковый месяц | В среднем отсутствует {доля} отдела (с учётом заявок на согласовании). Новые отпуска лучше планировать на {месяц} — там {доля}. |
| Нераспределённые дни | Не запланировано {N} дн.; до конца года {M} дн. Больше всего — {фамилии}. |
| Нет части в 14 дней | ТК РФ, ст. 125: одна из частей должна быть не короче 14 календарных дней. Сотрудники: {фамилии}. |
| Малочисленный отдел | В «{отдел}» {N} чел.: отпуск одного — уже {доля} отдела. Договоритесь о взаимном замещении заранее. |
| Всё в порядке | Покрытие отдела в норме. Конфликтов выше порога нет, отпуска распределены равномерно. |

# Ошибки API

Заголовок (`title`) problem+json показывается пользователю, если интерфейс не подставил более точный текст. Коды — только из каталога документа 2.

<!-- BEGIN:error-catalog -->
| Код (type) | HTTP | Заголовок (title) |
|---|---|---|
| `auth/invalid-credentials` | 401 | Неверный логин или пароль |
| `auth/token-expired` | 401 | Сессия истекла |
| `auth/forbidden` | 403 | Недостаточно прав для этого действия |
| `validation/invalid-field` | 400 | Некорректно заполнено поле |
| `validation/bad-date-range` | 400 | Дата окончания раньше даты начала или даты в прошлом |
| `not-found` | 404 | Запись не существует или удалена |
| `overlapping-request` | 409 | Период пересекается с существующей заявкой |
| `limit-exceeded` | 409 | Превышен остаток дней отпуска |
| `stale-state` | 409 | Данные изменились: обновите страницу и повторите |
| `last-admin` | 409 | Нельзя удалить или разжаловать последнего администратора |
| `department-not-empty` | 409 | В отделе ещё есть сотрудники |
| `rate-limited` | 429 | Слишком много запросов. Повторите позже. |
| `calendar-missing` | 400 | Для этого года не загружен производственный календарь |
<!-- END:error-catalog -->

# Согласование текстов

Тексты проверяет кадровая служба на соответствие локальным актам об отпусках. Тексты интерфейса и уведомлений меняются обычным PR; заголовки ошибок — только вместе с каталогом документа 2 и контрактом.
