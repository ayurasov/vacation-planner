# О документе

Документ сравнивает исходный прототип «Планировщика отпусков» (as-is) с корпоративной платформой версии 0.3.0 (to-be) по каждой функции. Для каждой возможности прототипа указано, что с ней сделано, а для возможностей, которых в прототипе не было, — в какой версии они появились. Документ — точка отсчёта для плана развития (документ 3) и технического задания (документ 8).

# Исходное состояние

Прототип — первый коммит репозитория `vacation-planner`: одностраничное приложение из одного файла `public/index.html` (около 4,6 тыс. строк) и тонкий сервер `server.js` на Express с SQLite. Функций много, но архитектура рассчитана на одного пользователя и локальный запуск под Windows (`start.bat`).

| Область | Состояние прототипа | Оценка |
|---|---|---|
| График отпусков | Работает; диаграмма Ганта поклеточно, около 48 000 DOM-узлов на 131 сотрудника | Сохранить, переработать отрисовку |
| Заявки и согласование | Работают; вся логика статусов — в браузере | Перенести на сервер |
| Баланс дней | Считается, лимит не соблюдается, праздники входят в отпуск | Перенести на сервер, исправить расчёт |
| Режим работы офис/удалёнка | Недельный шаблон и разовые исключения | Сохранить, перенести на API |
| Аналитика пересечений | Тепловая карта и конфликты считаются в браузере, медленно | Перенести на сервер и развить |
| Справочники | Отделы — строки в JSON-коллекциях | Сделать сущностями |
| Аутентификация | Пароли открытым текстом, проверка в браузере | Заменить полностью |
| Хранение | SQLite; браузер отправляет на сервер весь снимок данных (`PUT /api/state`) | Заменить гранулярным API |
| Тесты и CI | Отсутствовали | Создать |

# Критические дефекты прототипа

1. **Потеря данных при одновременной работе.** Любое действие отправляло на сервер снимок данных всей организации (около 274 КБ на 131 сотрудника); последний записавший затирал правки остальных.
2. **Нет серверной авторизации.** API принимал любые записи без входа, включая `POST /api/reset`, который уничтожал данные организации.
3. **Пароли в открытом виде** — в БД, в каждом ответе `GET /api/state` и в выгрузке XLSX.
4. **XSS через импорт**: имена и комментарии вставлялись в `innerHTML` без экранирования.
5. **Год зашит в код**: даты, праздники и подписи 2026 года — с 1 января 2027 года система неприменима.
6. **Нет журнала изменений**: восстановить, кто изменил или удалил отпуск, невозможно.
7. **Идентификаторы `Date.now()`** — коллизии при одновременных действиях.

Все семь дефектов устранены в версии 0.1.0 сменой платформы; подтверждающие тесты перечислены в документе 3.

# Ревизия по функциям

Вердикты: **сохранено** — функция перенесена с прежним смыслом; **переработано** — смысл прежний, реализация новая; **заменено** — подход изменён принципиально; **новое** — в прототипе не было.

## Сотрудник

| Функция | Прототип | Версия 0.3.0 | Вердикт |
|---|---|---|---|
| Заявка: даты, расчёт дней, комментарий | Проверки только в браузере | Сервер проверяет даты, пересечения (409) и лимит; форма показывает дни отпуска, календарные дни и праздники | Переработано |
| Баланс: норма, использовано, на согласовании, остаток | Мог уходить в минус; праздники считались днями отпуска | «Доступно» = норма + перенос − согласовано − на согласовании; праздники не входят (ТК РФ, ст. 120) | Переработано |
| Часть отпуска не короче 14 дней | Предупреждение | Отметка в балансе, аналитике и форме (ТК РФ, ст. 125) | Сохранено |
| Изменение, перенос, запрос удаления | Логика статусов в браузере | Конечный автомат на сервере; при отклонении переноса возвращаются прежние даты | Переработано |
| Подбор лучших дат | Нет | До пяти окон с учётом нагрузки отдела, праздников и своих отпусков | Новое |
| Режим работы офис/удалёнка | Шаблон и исключения в общем снимке | Отдельный экран, API, аудит изменений | Переработано |
| Уведомления о решениях | Локальное всплывающее сообщение | Центр уведомлений с непрочитанными | Новое |
| Смена пароля | Открытый текст | scrypt, завершение всех сеансов | Заменено |
| Тема, свёрнутое меню | Есть | Светлая, тёмная и системная темы; адаптивная вёрстка | Сохранено |
| ИП и самозанятые без отпуска | Есть | Тип занятости в карточке; заявки не оформляются | Сохранено |
