# ADR-001. Модульный монолит вместо микросервисов

Дата: 27.10.2026 · Статус: принято · Решение Р1 документа 1

## Контекст

500 пользователей, пики — десятки запросов в секунду; один бизнес-домен (отпуска); команда 2–3 разработчика с ИИ-ассистентами; эксплуатация — один стенд без выделенной SRE-роли.

## Решение

Один Node.js-процесс: Express + доменные модули `src/domain/*`, границы модулей — каталоги и правила импортов, а не процессы.

## Последствия

+ Простые деплой, отладка, транзакции (изменение + аудит в одной SQLite-транзакции).
+ Дешёвая разработка с ассистентами: один репозиторий, один контекст.
− Границы держатся дисциплиной кода (правила в AGENTS.md; контроль — ревью).
− Перегрузить один модуль — значит перегрузить всё; мониторинг по процессу, не по модулям.

## Критерии пересмотра

Появление второго домена с другой моделью нагрузки (например, рассылка писем этапа 2 как отдельный worker) или рост команды выше 6 — вернуться к выделению процессов.
