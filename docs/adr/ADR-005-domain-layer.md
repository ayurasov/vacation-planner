# ADR-005. Доменный слой без HTTP-зависимостей

Дата: 27.10.2026 · Статус: принято · Решение Р6 документа 1

## Контекст

В прототипе вся бизнес-логика (статусы, права, балансы) — в браузере и в обработчиках `server.js`. Для переноса на сервер нужен слой, тестируемый без HTTP и БД-сервера, который ИИ-ассистенты смогут проверять автотестами.

## Решение

`src/domain/<модуль>/` — чистые функции и сервисы: принимают данные и инфраструктурные интерфейсы (репозитории, часы), не импортируют express и не знают про запросы. `src/api/` — тонкие роуты: валидация (ajv), вызов домена, маппинг ошибок в problem+json.

## Последствия

+ Тест-таблица состояний заявок и расчёты баланса тестируются без супертестов — быстро и наглядно.
+ Правила в одном месте; фронтенд и будущие клиенты получают одинаковую семантику.
− Больше файлов и косвенности, чем «писать в роуте»; для 2–3 разработчиков — приемлемая цена.

## Правила

1. Домен не импортирует `express`, `node:http`; часы — `src/infra/clock.js`, случайность — `src/infra/random.js`.
2. Ошибки домена — типизированные (`DomainError` с кодом из каталога документа 2), роут превращает их в HTTP.
3. Репозитории передаются параметрами (инверсия), тесты — на in-memory реализациях.
