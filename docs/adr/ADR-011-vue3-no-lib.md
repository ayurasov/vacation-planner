# ADR-011. Vue 3 без компонентных библиотек

Дата: 27.10.2026 · Статус: принято · Решение Р7 документа 1 (v2.0)

## Контекст

UI должен выдержать стилистику внутренних продуктов (todo-planner/puls), а состав сторонних компонентов — проходить лицензионный контроль для реестра ОП с минимальными усилиями. Компонентные библиотеки (PrimeVue, Quasar) тянут десятки зависимостей и навязывают свой визуальный язык.

## Решение

Vue 3 + собственная дизайн-система: токены (`web/src/styles/tokens.css`, light/dark) и базовые паттерны (`base.css`) по ДНК todo-planner; компоненты пишутся под задачу; иконки — текстовые/inline-SVG.

## Последствия

+ Полный контроль вёрстки и веса: сборка 42 КБ gzip; SBOM客户端 minimal.
+ Дизайн-система компании переиспользуется дальше.
− Свои модалки/таблицы/календари — поддерживать самостоятельно (объём конечен: 7 экранов).

## Критерии пересмотра

Появление сложных редакторов/таблиц на сотни тысяч ячеек — точечно подключать прицельные библиотеки (с лицензионным контролем SBOM).
