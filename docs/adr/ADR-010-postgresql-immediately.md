# ADR-010. PostgreSQL 17 сразу, без SQLite-этапа

Дата: 27.10.2026 · Статус: принято · Заменяет ADR-004 · Решение Р2 документа 1 (v2.0)

## Контекст

ADR-004 предполагал SQLite на первых этапах с переходом на PostgreSQL по критериям. В версии 2.0 комплекта целевой масштаб поднят до 1000–5000 пользователей, задано требование эксплуатации «как продукт» (репликация, бэкапы WAL, конкурентная запись) и сразу заложены Docker-стенд и миграция данных прототипа.

## Решение

PostgreSQL 17 — единственная СУБД с v0.1.0. Доступ — только через Prisma (типобезопасность, миграции). Отдельная тестовая БД (`vacation_test`) для e2e.

## Последствия

+ Нет миграционного долга СУБД; конкурентность и транзакции «из коробки»; путь к репликации (v0.3) без смены фундамента.
− Обязателен запущенный PostgreSQL для локальной разработки и CI (закрыто docker compose и сервис-контейнером).

## Откат

Не предусмотрен (возврат к SQLite бессмыслен при достигнутой инфраструктуре).
