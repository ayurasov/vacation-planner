# ADR-008. Производственный календарь — таблица по годам

Дата: 27.10.2026 · Статус: принято · Решение Р10 документа 1

## Контекст

Список праздников и генератор дат зашиты в код на 2026 год: 1 января 2027 система перестаёт корректно считать рабочие дни и показывает пустой график. Переносы выходных в РФ меняются правительственными указами в течение года.

## Решение

Таблица `calendars(year, holidays, transfers)`, наполняемая: вручную администратором (импорт JSON) на этапе 1; автоматическим загрузчиком по указам — этап 2. Все расчёты рабочих дней идут через функции календаря (`analytics/coverage.ts`, `requests/balance.ts`) с данными из таблицы `calendars`; операции с датами года без календаря завершаются явной ошибкой `calendar-missing`.

## Последствия

+ Многолетность без релизов; поправки календаря — данными, не кодом.
− Кто-то должен вовремя загружать календарь: в конце года ответственность на администраторе (напоминание в ноябре — этап 2).
− Кэширование календаря в памяти сервера с инвалидацией по версии.
