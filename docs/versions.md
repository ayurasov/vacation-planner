## v0.2.1 — читаемые схемы и Gantt-полосы (28.10.2026)

- Ветка: `v0.2.1`. Merge в `main`, тег `v0.2.1`. Автор: **ayurasov** (исполнение — ИИ-ассистент ZCode/GLM).
- Исправлено отображение схем: mermaid-подписи в foreignObject вырезаются Gitea/GitHub — документы переведены на PNG (одинаковый вид везде), PDF встраивает PNG напрямую.
- График: полосы отпусков вместо поклеточной заливки, месяц-разделители, липкая колонка, линия «сегодня», KPI-строка.
- Навигация: коллапс сайдбара до 60px, заголовок страницы и дата в топбаре.
- Gitea CI: добавлен SBOM-гейт лицензий; полный конвейер (тесты 22, сборки, линтеры, SBOM, deploy+smoke) прогоняется при мажорных правках.

## v0.2.0 — схемы, фирменный дизайн и первые выгрузки (27.10.2026)

- Ветка: `v0.2.0`. Merge в `main`, тег `v0.2.0`.
- Автор: **ayurasov** — постановка и решения. Исполнение — ИИ-ассистент (ZCode, GLM).

### Что увидит пользователь

- Интерфейс приведён к дизайн-стандарту внутренних продуктов: тонкие векторные иконки вместо эмодзи, фирменный знак в меню и на входе, точные фирменные цвета кнопок и бейджей, тёмная тема в той же палитре.
- Руководители и администраторы выгружают отпуска за период в Excel одним нажатием; выгрузка не содержит логинов и паролей.

### Инженерное

- Комплект документации получил 9 схем в нотации примера (C1/C2/C3, ER-модель, развёртывание, состояния заявки, три sequence-сценария); PDF-версии со встроенными векторными схемами.
- Безопасность: лимит попыток входа 10/мин с адреса (429 с Retry-After), заголовки X-Content-Type-Options/X-Frame-Options/Referrer-Policy/Permissions-Policy.
- SBOM-гейт впервые отработал по назначению: зависимости exceljs (jszip MIT/GPL, chainsaw MIT/X11, buffers, pako MIT+Zlib) разобраны по политике документа 11 — все разрешительные (825 компонентов, вердикт: препятствий нет).
- Тесты: 22 e2e (+лимит входа, +выгрузка и права на неё).

## v0.1.0 — зрелая платформа вместо прототипа (27.10.2026)

- Ветка: `v0.1.0`. Merge в `main`, тег `v0.1.0`.
- Автор: **ayurasov** — постановка, решения, ревью. Исполнение — с ИИ-ассистентом (ZCode, модель GLM): генерация кода, тестов и документации по настоящему комплекту.

### Что увидит пользователь

- Современный интерфейс в дизайн-системе внутренних продуктов: светлая и тёмная темы, боковое меню, карточки; графики отпусков на весь год с фильтром по отделам и поиском; заявки создаются в диалоге с превью календарных дней; руководитель согласует или отклоняет с обязательной причиной; уведомления о решениях приходят в раздел «Мой отпуск».
- Вход по корпоративному логину и паролю; смена пароля в настройках; администратор заводит сотрудников с автогенерацией логина и одноразового пароля, ведёт отделы и проекты, смотрит журнал всех изменений.

### Платформа (для инженерной приёмки)

- Сервер: NestJS 11 / TypeScript strict / Prisma 6 / PostgreSQL 17; API v1 по контракту (`contracts/`); RFC 9457; JWT access 15 мин + refresh с ротацией; scrypt-пароли; аудит и уведомления в одной транзакции с изменением; 19 e2e-тестов (+17 дымовых проверок API).
- Клиент: Vue 3 + Vite + Pinia + TS; без компонентных библиотек (минимальный SBOM); сборка 42 КБ gzip.
- Поставка: docker compose (postgres / server / web+nginx); миграции при старте; данные прототипа перенесены (131 сотрудник, 268 заявок, 14 отделов).
- Состав и лицензии: CycloneDX SBOM на оба пакета (691 компонент, все лицензии разрешительные) + автогенерируемый отчёт соответствия для реестра отечественного ПО (документ 11).
- Документация: комплект 0–11 с PDF-версиями (`docs/pdf/`).

### Известные ограничения (переносятся в v0.2.0)

- Выгрузки XLSX, панели отдела/проекта и аналитика пересечений — в v0.2.0.
- Обновления графика в реальном времени — перезагрузкой/операцией (SSE — v0.2.0).
- Лимит частоты входа и CSP-заголовки — v0.2.0.
