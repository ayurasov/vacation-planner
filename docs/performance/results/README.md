# Результаты нагрузочных прогонов 1.0.0

Доказательства к отчёту `docs/performance/report-v1.0.0.md`. Каталог — один прогон `tools/load/pinned.sh`:

| Файл | Что внутри |
|---|---|
| `config.txt` | Дата, коммит, узел, ядра стенда и генератора, число процессов API, PostgreSQL, численность и размер базы |
| `result.md`, `result.json` | Итог генератора: операции, ошибки, p50/p95/p99/max, поток событий |
| `resources.csv` | Ресурсы каждые 5 с: ядра API, PostgreSQL и генератора, RSS и куча V8, потоки событий, соединения |
| `slow-routes.txt` | Медленные запросы API по маршрутам (журнал сервера, порог 500 мс) |
| `top-queries.txt` | Самые дорогие запросы `pg_stat_statements` |

| Прогон | Сборка | Назначение |
|---|---|---|
| `2000-1cpu-average-before` | до исправления волны перечитываний графика | Симптом узкого места 1 |
| `2000-1cpu-average`, `2000-1cpu-spike` | с исправлениями | Сайзинг 2000 сотрудников на 1 vCPU |
| `1000-1cpu-average`, `1000-1cpu-spike` | с исправлениями | Сайзинг 1000 сотрудников на 1 vCPU |
| `2000-1cpu-stress` | до исправления ложного `revoked` | Запас на 1 vCPU; ошибки 6 и 7 отчёта |
| `2000-1cpu-stress-fixed` | с исправлением ложного `revoked` | Перепроверка: `revoked` 199 → 0 |
| `2000-1cpu-peaks-before` | до исправления волны уведомлений | Пики на фоне `average`: `peaks.json` — итог пиков, `slow-by-10s.txt` — медленные запросы по 10 с (узкое место 5) |
| `2000-1cpu-peaks` | с исправлением волны уведомлений | Пики после исправления: те же файлы |
| `failures-before` | до исправления остановки API | Отказы под нагрузкой: `events.log` — время каждого отказа |
| `growth` | с исправлениями | Рост данных: размеры до и после сроков хранения, копирование и восстановление |
| `mail-before` | до исправления очереди писем (`743c7a9^`) | Открытие кампании на 2000 сотрудников: письма по 15 с (узкое место 3) |
| `2000-1cpu-soak-interrupted` | с исправлениями 1–7 | Первый прогон 8 часов, прерван перезапуском стенда на 5 ч 16 мин: ресурсы по часам и медленные запросы |
| `2000-2cpu-stress` | со всеми исправлениями сервера | Запас на 2 vCPU: ×8 в требованиях |
