# О документе

Документ — шаблон сведений о стоимости программы «Планировщик отпусков» версии 1.0.0, которые размещаются на сайте правообладателя и прилагаются к заявлению о включении в реестр российского ПО. Цены, сроки и условия определяет правообладатель; в шаблоне они отмечены `[заполняет правообладатель]` или `[ ]`. Структура предусматривает две модели лицензирования — по числу сотрудников и на экземпляр программы; правообладатель оставляет одну или обе. Перед публикацией документ согласуется с бухгалтерией и юристом правообладателя.

Правила подсчёта при лицензировании по числу сотрудников:

- учитываются сотрудники с действующей учётной записью — те, кто ведётся в графике отпусков организации; уволенные (отключённые) сотрудники не учитываются, их история сохраняется;
- сотрудник учитывается один раз независимо от ролей (сотрудник, руководитель, заместитель, кадровая служба, администратор) и способа входа (пароль или единый вход);
- учётные записи, созданные только для администрирования, `[учитываются / не учитываются]`;
- число сотрудников видно администратору в разделе «Сотрудники»; сверка — `[раз в год / при продлении поддержки]`.

Один экземпляр программы обслуживает одну организацию: ведение нескольких юридических лиц в одном экземпляре в версии 1.0 не поддерживается.

# Пробный период

Для оценки программы предоставляется `[заполняет правообладатель: бесплатная пробная установка на N дней / доступ к демонстрационному стенду]`. Пробная версия функционально не ограничена и может быть наполнена демонстрационными данными (131 сотрудник, 14 отделов); данные пробной установки сохраняются при покупке лицензии.

# Порядок приобретения

1. Запрос коммерческого предложения: `[e-mail, телефон, форма на сайте]`.
2. Согласование числа сотрудников, модели лицензирования, услуг и сроков.
3. Заключение лицензионного договора (проект — в комплекте документов).
4. Оплата по счёту.
5. Передача дистрибутива с контрольными суммами SHA-256 и документации по акту приёма-передачи.
