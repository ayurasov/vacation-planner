# Схемы комплекта документов

Исходники схем; рендер в PNG — `make docs-diagrams` (результат в `docs/images/`).

| Префикс | Назначение | Формат |
|---|---|---|
| `a0*` | архитектура: контекст, контейнеры, слои сервера и клиента, поставка | Mermaid / HTML |
| `er-*` | модель данных по доменам | Mermaid erDiagram |
| `s0*` | сценарии: вход, обработка запроса, создание и согласование заявки, график | Mermaid sequence / flowchart |
| `st*` | состояния заявки | Mermaid stateDiagram |
| `f0*` | роли и возможности | HTML |
| `l0*` | жизненный цикл выпуска и конвейер CI | HTML |

Правила оформления (общий стандарт с todo-planner):

- палитра: синий `#4f7cff` — компоненты системы, зелёный `#22a06b` — данные, фиолетовый — сервисы,
  оранжевый — домен и предупреждения, красный — ошибки и защита, серый — внешние системы;
- послойные схемы — HTML/CSS (`diagram.css`), снимается блок `.wrap`;
- в документах используются только PNG: одинаковый вид в Gitea, GitHub, PDF и DOCX;
- заголовки групп Mermaid — с `#nbsp;` вместо пробелов (иначе переносятся поверх блоков).
