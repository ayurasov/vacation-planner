# P07. Критическое ревью (человек)

Чек-лист для технического лидера по PR истории {ID} (ревью ТЛ = да):

1. Решения, не описанные в документах? Ассистент обязан перечислить их в PR.
2. Безопасность: auth, права, хеши, журналы — построчно.
3. Миграции: up/down прогнаны на копии данных.
4. Гонки: сценарии параллельных действий под тестами.
5. Соответствие контракту — diff contracts/ отсутствует (или согласован отдельным PR).
6. CHANGELOG и «что осталось» честны.

Вердикт: принять / доработать (список) / отклонить (причина).
