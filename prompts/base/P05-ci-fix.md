# P05. Упал CI

Конвейер {ссылка на прогон} красный на коммите {sha}. Локально всё было зелёным.

1. Прочитай лог задачи(й): checks (lint/test/contract) или smoke.
2. Воспроизведи локально той же командой; если окружение (Node 22 vs 20) — проверь на обоих: `nvm use 22 && npm ci && npm test`.
3. Частые причины: версия Node, отсутствие prebuilt для better-sqlite (поставь build-essential python3), тайминги ожидания сервера в smoke.
4. Исправь минимально, прогони полный набор локально, запушь.

Если падение вызвано контрактом или требует изменения docs — P12.
