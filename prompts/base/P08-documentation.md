# P08. Документация

1. Запись в CHANGELOG.md (Added/Fixed/Changed по факту, без маркетинга).
2. Если изменилось поведение, видимое пользователю, — тексты есть в docs/specs/05-messages.md? Если нет — сформулируй заявку на изменение документа (в PR, файл не править).
3. Если появился новый сценарий эксплуатации — заметка в docs/progress/.
4. Обнови docs/progress/iteration-N.md: статус истории, факт трудозатрат, наблюдения.
