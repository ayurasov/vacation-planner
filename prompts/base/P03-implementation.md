# P03. Реализация

Реализуй минимальный код, проходящий тесты P02. Правила AGENTS.md обязательны:

- Логика — в сервисе домена `server/src/<домен>/`, контроллер тонкий (DTO-валидация → сервис → problem+json); чистые расчёты — в модулях без БД.
- Изменение данных + `audit_events` в одном `prisma.$transaction`; гонки — `SELECT … FOR UPDATE`.
- Дата расчёта — аргументом; `new Date()` только для «сейчас» в точке входа.
- Ошибки — только из каталога docs/specs/02-api-spec.md (раздел «Ошибки»).
- Клиент: запросы только через `web/src/api/client.ts`, стили — токены `tokens.css`, без `v-html`.
- Не трогать без ревью владельца: contracts/, docs/specs/, prisma/migrations/, server/src/auth/, зависимости.

Запусти `make test` и `cd web && npm test` — все тесты истории зелёные? Перечисли незакрытые тесты, если есть, и почему.
