# P04. Самопроверка

Выполни и приложи вывод каждой команды:

1. `npm run lint` — исправи все замечания.
2. `npm test` — все зелёные.
3. `npm run contract:check` — контракт валиден.

Затем пройдись по чек-листу:
- Критерии приёмки истории {ID} — каждый подтверждён именем теста.
- Нет изменений вне задачи (git status чист от лишнего).
- Секретов/паролей/токенов в коде, тестах и журналах нет.
- Миграции обратимы, путь отката описан.

Найденное исправь и повтори команды.
