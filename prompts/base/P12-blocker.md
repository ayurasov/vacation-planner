# P12. Блокер

Останови работу. Не угадывай и не расширяй полномочия.

Сформулируй для человека:
1. Что делаю (задача, шаг).
2. Что мешает: контракт не покрывает / документы противоречат / нужна зависимость / миграция необратима без решения / права доступа шире задачи.
3. Варианты решения с плюсами/минусами и рекомендацией.
4. Что можно сделать без решения (безопасная часть).

Сохрани состояние: ветка, коммит, незакрытые тесты — чтобы продолжить после ответа.
