# Промпты для разработки с ИИ-ассистентами

Итерационная модель и базовый цикл историй. Правила — `docs/specs/06-ai-rules.md` и `AGENTS.md`.

## Модель работы

- Этап 1 = итерации I1–I4 по две недели (соответствие неделям — `docs/specs/03-backlog.md`).
- Итерация: планирование всех историй (P01) → цикл «история за историей» (P02→P09) → закрытие итерации (P10, файл `docs/progress/iteration-N.md`).
- Одна сессия ассистента = одна история. Контекст между сессиями — через `docs/progress/`, а не пересказ.
- Блокеры и дефекты — P12 и P11 соответственно.

## Базовые промпты

| Файл | Когда |
|---|---|
| `base/P01-story-plan.md` | перед началом истории |
| `base/P02-tests.md` | тесты до реализации |
| `base/P03-implementation.md` | реализация |
| `base/P04-self-check.md` | самопроверка |
| `base/P05-ci-fix.md` | упал конвейер |
| `base/P06-independent-review.md` | ревью вторым ассистентом |
| `base/P07-critical-review.md` | ревью человеком |
| `base/P08-documentation.md` | CHANGELOG и заявки на docs |
| `base/P09-story-close.md` | закрытие истории |
| `base/P10-iteration-close.md` | закрытие итерации |
| `base/P11-defect-analysis.md` | разбор дефекта |
| `base/P12-blocker.md` | остановка и эскалация |

## Признаки проблем

Ассистент предлагает менять контракт, добавлять зависимости, «улучшать попутно» — останови сессию и разбери по `docs/specs/06-ai-rules.md` раздел 9.
